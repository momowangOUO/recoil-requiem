# 场景与任务 UI 标准

状态：用户批准的生产约束；新UI和新关卡已接入，实际验收见UI_ACCEPTANCE.md和VALIDATION.md。角色关节细则继续引用 docs/ART_STANDARD.md 与素材来源记录，不在此复制易过期的锚点数值。

## 几何与图层

|对象|制作方式|检查|
|普通道路、地基、楼梯、实体平台、桥、门洞、大设备|真实 3D，顶面与侧面分别贴图|二维站立线与三维支撑一致，道路下面不镂空|
|门、升降机、活动桥|独立运动的结构件，状态由玩法数据驱动|碰撞与视觉同时开启，关门前有可用退路|
|人物、敌人、NPC|二维像素角色，关节或完整动作帧|统一比例，枪手肩腕连接，受击和预警可读|
|挂画、墙面纹样、远处窗饰|贴墙二维图像|不把需要厚度的大设备伪装成一张画|
|天空、月亮、远景城堡|独立二维层|视差分别控制，避免月亮与建筑一起漂移|
|下方近处城墙、枝叶|世界定位的二维前景|可以柔化采样，不能全屏虚化；禁止贴屏漂浮|

平台、人物和可玩纹理最近邻采样。UI 文字保持原生分辨率，前景允许局部线性采样。侧面会明显暴露的物件用 3D 或补侧面，不能拉伸整张图集伪造体积。

柱脚、栏杆脚和设备底座要有支撑。背景柱、书架位于平台后方，不穿进顶面；玫瑰不塞地缝。三枪最近与最远镜头、跳跃、高台、低处均截图检查，确保前景不挡关键落点和敌人预警。

## 任务界面

左下战斗信息保留：生命、当前枪、清晰弹量、六槽关系；只有有效射击后的短时间显示弹药比例环，换弹环使用真实进度。保持短按 Q 切枪、长按查看。

右上追踪一个主目标和一条自选支线。目标写当前动作与已知地点，不写道德评价；未知人物身份不提前出现在标题里。完成提示短暂显示后收起，不累计成一整屏清单。

日志区分任务进展、发现的线索、认识的人和发生的后果。地图只展示已经探索的结构、见过的门、已开捷径和检查点；未知区域只显示入口，不直接画出秘密路线。地图和日志打开时暂停，恢复时清除旧开火输入。

美术以旧银、深红、象牙色为主，少量机械细节。先生成完整布局风格稿并在实机上试装，再拆边框、图标、分页、印章。所有文字、弹量和进度由原生 UI 绘制；不把中文烘焙到图内，不用黑色大板盖住世界。

每张生产素材登记用途、源图、提示词、尺寸、透明方式、采样方式、拆分记录、运行引用和最终验收截图。失败候选不混入运行目录。既有素材仅在确认引用与来源用途后移除。

## 2026-09-14 可读性修订
任务、地图和对白正文使用无花纹平底；禁止整张图集作为九宫格底板拉伸。文字距离面板外边至少36设计像素；装饰只能位于正文安全区之外。按钮必须具备正常、悬停、按下、焦点、禁用状态，焦点仅画边线。功能检查通过不代表审美验收通过。
