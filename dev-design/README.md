# 开发设定入口

更新：2026-09-14。

本目录用于整合《反冲挽歌》的开发规则、人物、故事、任务和关卡。当前仅建立执行入口，重构尚未实施。请先读 [执行记录](IMPLEMENTATION.md)，再读取与当前任务有关的资料，不要扫描全部文档。

## 已确认方向

- 主角是神秘的女性吸血鬼，猎杀同族；所有人物都在游戏过程中结识。她为什么猎杀同族尚未选定，需要先比较动机并制作角色卡。
- 保留哥特、蒸汽朋克题材，以及真实 3D 场景和精细二维像素人物。人物外观与现有手臂实现约束仍以根 AGENTS.md 和现行美术标准为准。
- 故事偏黑暗、邪道，重要悲剧由人物行动和已建立的世界规则造成。关键损失固定，探索与选择改变部分后果，不预设主角代表正义。
- 全城互通探索；首轮完整制作猩红修道院及连接据点，其他城区先设计连接。
- 保留跳跃、反冲、三枪与六枪槽。扩展空间、路线和遭遇，不靠加血量代替关卡深度。
- “换心维生”“院主出售遗体”已退出默认候选，不得作为正式世界观或新故事的起点。旧搭档、熟人引路等内容也不得恢复。

## 资料优先级

用户最新确认高于旧文档。此处明确确认的内容用于约束新设计；未迁移的旧故事只是历史参考，不自动成为新设定。现有代码仍运行旧版本，不能把新计划描述成已经实现。

故事工作使用 game-narrative 及对应角色模板；中文策划使用 game-design-natural-writing-zh；逻辑完成后使用 humanizer-zh 检查中文。game-story-workflow 尚未创建和安装，不能宣称已调用它。
