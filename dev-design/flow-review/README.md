# 反冲挽歌 猩红修道院完整游玩流程

状态：2026-09-22 待审设计稿。沿用已确认的莉芙动机及修道院事件线；新增教学、路线和演出安排尚未接入游戏。示意图是图像生成工具制作的伪游戏截图，不是实机验收截图。

本稿要解决的是：玩家进入游戏后，能够明白自己来找谁、眼下往哪里走、做成一件事后发生了什么；随后在完整的探索与战斗过程中认识人物，最后看到追猎留下的结果。

人物比例和镜头以现有游戏为准。生成图不能反过来要求放大主角、缩小关卡或把透视场景改成纯平面。实施时须做同机位对照，检查人物占比、道路顶面、建筑底部、窗墙分层与连续移动中的视差。
