# 修道院十二段演出施工表

2026-09-30。实施依据为用户批准的《画面清晰度、对白稳定性与章节演出改造》计划。本文规定画面、事件衔接和验收，**不是完成记录**。实际接入、截图及缺项由本目录的实施记录另行登记。

## 不改动的事实

莉芙主动追猎维拉，想知道她面对死亡会怎样行动。维拉准备离开修道院；玛拉接收生意，赛琳负责交接线路。六名人物在本章初识。赛琳战败后存活，维拉在实际首领战后死亡。支线改变物品归属、通路和战后关系，不解锁无损结局，也不替维拉的临终动作下结论。

正式对白继续取自 `monastery-v2-review.md` 及 `monastery-flow-review.md`。新字卡逐字见 `game-text/chapter-staging-review.md`，数据见 `data/campaign/chapter_staging.json`。新 cue ID 只记录演出，不替代现有任务事实或门锁条件。

## 统一画面与控制

沿用像素角色、旧银边饰、深红分格和象牙色正文。人物特写从现有像素立绘取景，脸部保持原像素密度，莉芙用严肃表情。场景仍呈现真实道路顶面、墙窗错层和纸板建筑；漫画卡不能长期遮住路面。分格推进约 0.18 秒，停留后约 0.18 秒退出，时长计入数据中的 `duration`。

三秒完整卡在玩家站稳、未交火、没有其他对话或菜单时播放。若触发时正在坠落或换位，保留事件，等安全落脚后再播放；不能把角色吸到演出点。完整卡期间暂停双方伤害与物理，保留位置、速度、弹量及装填进度。结束和跳过时清掉旧开火输入，先恢复画面，再接受新输入。

一秒现场短卡不抢镜头、不暂停战斗，放在安全区上沿。合作和第一名守卫使用这一形式，不能遮住预警。教学、任务更新、对白与完整卡串行显示；一个事实同时产生多条反馈时，先完成现场动作，再播对白，最后显示结果短卡。普通 UI 提示不重复念同一结果。

跳过只结束装饰层。对白仍逐句推进，交付与发车必须读取原有选项；卡片不能写入任务结果。暂停、失焦时演出计时也暂停。只在成功提交事实后播结果；存档失败保留现场选择，不先放出“已完成”。旧存档按既有进度略过前段卡，不能一加载就依次补播。

## 接入边界

- `arrival` 与 `departure` 是阶段入口；`mara`、`vira`、`celine_duel`、`vira_duel` 先播卡再接对白。`celine_after`、`tools`、`records`、`return` 在对应对白结束后播；不能把对白队列覆盖掉。
- `vira_after` 的三秒卡不能吞掉已有三秒现场安静时间。先留现场，再提示回程；两者可以共用一次时间线，但前半段不能压上大字。
- `celine_after` 完成后只允许维拉进入待战状态；玩家尚未靠近时不得开始攻击或被远处射击。
- 提前调查与任意支线顺序继续成立。玩家已进入后段时，不补播路过但没有发生的合作和交付；略过第一名守卫也不伪造击杀。
- 开场教学继续由现有动作事实驱动。演出结束后只恢复当下仍适用的一条，不累积弹出已经完成的操作提示。
- 第一人称感受只来自既有角色对白。卡片不宣称维拉“恐惧了”“露出真面目”，也不把赛琳描述成阻碍正义的敌人。

## 图稿、施工与验收

先按十二段各出一幅伪游戏截图，双路线和三个支线在同幅中分格标明不同结果。图稿使用实际机位和角色占比；完整卡的立绘与背景可以分层，中文由原生 UI 绘制。每图旁保存实际触发条件、已用图层和实景差异。生成一张漂亮的全景不能代替机关动作、人物行走或连续镜头验收。

连续切片按“抵达、石阶、首场交锋、玛拉、维拉”顺序先跑通。之后跑双路线至回访，分别覆盖跳过、失焦、死亡、旧档继续和写盘失败。检查一项事实只产生一次结果、地图通路与提示一致、发车未确认时仍能返回，以及对白出现首帧没有文字跳位。截图检查正文和纹样，连续录像检查输入恢复与演出衔接；自动回放不能记为真人试玩。
