# 修道院开场与任务追踪修订稿

状态：在 2026-09-14 已批准事件线与对白内补充开场引导，不新增剧情事实。运行文本接入后仍以本稿逐项核对。

## 事实与角色边界

- 莉芙只知道维拉准备从修道院离开，并主动来追她；工具归属、人员关系和行李内情仍需在现场得知。
- 莉芙在意维拉临走还会带走什么。她的好奇不等于正义，也不能证明临危反应是维拉的“真实本性”。
- 开场不引入旧相识、营救任务、换心、遗体交易或幕后主谋。
- 所有人物仍是初次见面。开场不提前说出玛拉、伊娜、鲁卡或赛琳的身份。

## 首次进入时的自言自语

这两句显示在右上任务追踪框内。见到玛拉、主目标更新后自动收起，不打开整页面板。

| `mon.opening.target` | 莉芙／已知目标 | 维拉今晚要离开修道院。 |

## 通用界面反馈

| ID | 用途 | 文字 |
|---|---|---|
| `mon.ui.controls` | 追踪器页脚 | E 交谈／调查　J 日志　M 地图 |
| `mon.ui.opening_controls` | 首次目标期间 | A / D 移动　空格跳跃<br>鼠标瞄准　左键开火 |
| `mon.ui.completed` | 任务切换短提示 | 已完成：{objective} |
| `mon.ui.end_talk` | 对白关闭按钮 | 结束交谈 · Esc |
| `mon.ui.interact` | 邻近人物或物件 | E　{action}{target} |
| `mon.action.tools` | `tools` 交互目标 | 工具箱 |
| `mon.action.records` | `records` 交互目标 | 维修记录 |
| `mon.action.luggage` | `luggage` 交互目标 | 行李 |
| `mon.action.departure` | `departure` 交互目标 | 发车机关 |
| `mon.action.exit` | `exit` 交互目标 | 后门 |
| `mon.action.shortcut` | `*_travel` 交互目标 | 货运捷径 |
| `mon.action.gate` | `gate_*` 交互目标 | 通道机关 |

`{objective}` 只替换为上一条主目标标题。`{action}` 和 `{target}` 只显示当前可执行交互，不提前揭示陌生人物身份。实际组合为“E　调查　工具箱”“E　阅读　维修记录”“E　操作　发车机关”等，不回退为含糊的“E　使用”。完成提示约三秒后收起，不累计历史清单。日志和地图仍使用“关闭 · Esc”。

开场只列移动、跳跃、瞄准和开火。见过玛拉后，这两行自动替换为一行 `E / J / M` 提示；邻近人物或物件时，下中部再显示当前可执行的 E 操作。

## 接入与检查

- 运行 ID、姓名、地点和任务状态保持不变；本稿不改变地图连接、支线排他关系、发车条件或固定结局。
- 自言自语只在第一目标期间显示。主目标更新后消失，旧目标以完成提示短暂保留。
- 玩家可以提前探索内庭，但在尚未见到玛拉或维拉时，追踪器仍显示当前真正可执行的会面目标；不会提前指向尚不能启动的发车机关。
- 回访完成后，追踪器显示本段追猎已经结束。后门提示只说明它通往旧运输线，不暗示尚未实现的下一城区已经开放。
