# 保存状态提示

状态：已按实际触发条件自检，可接入。仅描述保存状态，不涉及剧情。
目标：CampaignSession.SAVE_COPY；运行时通知与后续菜单共用。
正常新开局、读取和保存不弹提示。恢复提示保留在保存状态中；失败提示在问题解决前定期重显。

| ID | 触发条件 | 接入正文 |
|---|---|---|
| ready | 当前可以正常保存 | 自动保存已开启。 |
| recovered | 有效备份已恢复为主存档 | 已从备份恢复进度，可以继续保存。 |
| load_failed | 原存档不可用，备份也无法恢复 | 存档无法读取，自动保存已暂停。原文件已保留。 |
| write_failed | 本次写入失败 | 进度尚未保存。请检查存储空间或写入权限后重试。 |
| disabled | 测试或调用方明确禁用自动保存 | 自动保存已关闭。 |

检查：恢复成功才显示“可以继续保存”；失败不承诺已保存；错误码和保留路径独立供菜单查询，不塞进短提示。
