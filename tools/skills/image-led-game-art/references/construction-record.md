# 最小施工与验收记录

只保留当前切片需要的内容。

| 对应项 | 记录 |
|---|---|
| 目标 | 采用原图路径、生成工具、提示词、视口／比例、哪些部分是参考而非事实 |
| 权威数据 | 路线／碰撞／状态文件；不可随美术调整的内容 |
| 主体 | 原图区域 → 资源与节点；大小、锚点、深度、移动方式 |
| 拆分 | 原图实际宽高、alpha检查、实际裁区；不要照抄提示词中的格数 |
| 状态 | 哪些图层随探索、门、交互或进度改变，哪些完全静态 |
| 对照 | 原图、同视角实机图、连续动作记录、差异及处理 |
| 交付 | 通过的检查、实际打包内容、未完成部分 |

地图要分别核对可行走结构和建筑辨识；装饰图不能擅自补桥、楼梯或入口。等比全图与局部视图用途不同，不能为了填满界面扭曲游戏坐标。若真实地图比例与概念图不一致，先修概念的构图要求或明确概览转换，而非宣称完全一致。

侧向场景要检查最远镜头仍有图层覆盖、贴片底边不暴露、窗洞具有可解释的层次、基础与支承不断开。近景上沿的世界锚点与下方素材覆盖是两件事，修露底不能让轮廓追随跳跃镜头。

UI检查文字安全区、真实中文长文本、按钮状态、布局范围与图案变形。静态美术稿不替代真实进度、动态文本或交互状态。
