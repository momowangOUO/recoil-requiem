# 玫瑰与装饰接地修订

2026-09-11。原先栏杆统一放在固定高度，跨过了钟楼外廊的低处和花园的渠底；柱脚、花盆和书架也使用与平台无关的坐标。透视镜头使这些悬空和错位更加明显。

现在栏杆按真实实体平台分段生成，立柱底部与平台顶面重合，边缘留出安装余量。机关平台的栏杆归入同一组可见物件，平台未放下时不会留下半空栏杆。其他落地装饰从关卡平台数据取得支撑面，并检查完整底面的横向范围与景深范围；找不到足够宽的实体面就不摆放。当前装饰只选永久平台作为底座，避免机关开启时发生位置跳变。书本底部与书架层板贴合，钟增加了接地立柱与吊杆。

玫瑰采用 imagegen 绘制的 rose_bush_v1.png，含真实透明通道。整簇为一个固定平面的 Sprite3D，宽约 58 逻辑像素，保留最近邻采样并接受环境光。运行时按不透明包围区域定位花茎根部，恰好贴合石花盆顶面；不使用圆柱花头、立方体花茎或随镜头旋转的立体花瓣。源图和提示词见 assets/environments/crimson/ROSE_SOURCE.md。

用户补充要求玫瑰不能塞进地缝。因此花盆与花丛按完整摆放空间检查：底座必须全部受支撑，平台上方保留至少 90 逻辑像素的净空；尚未放下的机关桥也参与遮挡检查。当前只保留西侧踏台、西侧高廊和东侧高廊三处完整花丛，拒绝渠缝和低平台下面的摆放。花茎不得穿进石缝或依赖平台遮住底部。

验证入口 tests/test_decor_support.gd：从旧实现复现了悬空和圆柱玫瑰失败，修复后检查栏杆、柱脚、花盆、书架、钟架与平台的真实底面接触，检查透明贴片及花茎根部，还覆盖机关栏杆显隐。tests/capture_environment.gd 增加渠底与外廊落脚点的近景截图。碰撞、通路、镜头控制和角色动作不由装饰改动。
