# 重力与移动手感调整

2026-09-08：用户反馈空中太飘、落地不够干脆，边跑边开枪有滑动感。本次默认使用 Responsive 参数，同时保留 GDD 参数按钮用于对照。

## 已定位的问题

空中水平输入原来每帧无限叠加，按住两秒达到约 760 px/s；松手后没有低于速度软上限时的空气减速，一秒后速度仍不变。地面跑动只有一套趋近速度处理，霰弹的完整水平反冲会把向前 150 px/s 改成倒退 570 px/s；按住前进 200 毫秒后仍在倒退。动画只看水平速度，导致被反冲推动也在跑步，后退射击时脚步方向也不匹配。

## 当前规则

- 空中方向输入逐渐趋近 220 px/s；已存在的更高反冲速度不会被巡航上限直接截断。
- 松开方向键时，以 180 px/s² 减少水平漂移；反向输入仍可修正速度。
- 地面水平反冲乘 0.45，代表地面支撑；垂直反冲保持完整。已经起跳的同帧射击使用完整空中反冲。
- 地面加速 2400、减速与反向制动 3200 px/s²。霰弹仍有瞬间后退，但能较快恢复前进。
- 重力始终为同一个常数，不按枪械或升降状态暗中切换。Responsive 为 2100；配套校准跳跃与武器反冲，保留原有机动高度和缓降用途。
- 跑步需要方向输入与实际前进速度一致；帧率随速度变化。面对瞄准方向后退时反向播放，纯反冲滑动使用站姿。

## 可对照参数

| 参数 | GDD | Responsive（默认） |
|---|---:|---:|
| 重力 | 1500 | 2100 |
| 跳跃冲量 | 460 | 545 |
| 地面加速 / 减速 | 1400 / 1800 | 2400 / 3200 |
| 方向输入空速上限 | 760 | 220 |
| 空中松手减速 | 0 | 180 |
| 地面水平反冲比例 | 1 | 0.45 |
| 左轮反冲 | 250 | 300 |
| 霰弹反冲 | 720 | 850 |
| SMG 反冲 | 92 | 145 |

伤害、射速、弹量、装填、敌人击退和自然下落终端 900 均未改变。武器 `.tres` 保存原 GDD 数据；新配置只作用于运行时副本。GDD 按钮恢复旧参数，控制器缺陷修正及步伐同步仍保留，不代表切回旧代码。

## 测量与验证

`tests/test_movement_feel.gd` 使用实际角色控制器、物理碰撞和武器运行状态，固定 60 Hz 注入输入。`tools/run_checks.ps1` 在 30/60/144 FPS 下分别运行历史基线检查与新手感检查。

| 测量 | 修改前 | 修改后 |
|---|---:|---:|
| 空中按住方向两秒后的速度 | 760 | 220 px/s |
| 随后松手一秒的速度 | 760 | 40 px/s |
| 这段松手期间的漂移距离 | 760 | 128.5 px |
| 地面前进时左轮开火瞬间速度 | −100 | +15 px/s |
| 地面霰弹开火 200 ms 后速度 | −290 | +150 px/s |
| 霰弹首个射击物理帧之后的额外倒滑 | 83.7 | 6.6 px |
| 普通跳跃高度 | 74.49 | 75.41 px |
| 普通跳跃总腾空时间 | 0.633 | 0.550 s |

新参数下两秒静止空中自由下落 1614.58 px，SMG 朝下持续射击净下降 610 px，约为自由落体的 37.8%；同时按 W 时仍净下降 247 px。空中霰弹产生的超巡航速度也保留。

基线检查 75 项，新手感检查 13 项，另有 UI 和键鼠事件回放。结构化测量在 `artifacts/movement-feel.json`，修改前记录在 `movement-feel-before.json`。这些结果证明控制和动画规则已改变；是否足够干脆仍需结合用户的实际试玩反馈继续判断。

新参数的渲染键鼠回放共 13 项玩法检查、10 项截图保存检查，全部通过。新增了边跑边连射、松手停止和后退步伐三项；边跑边连射时保持 +150 px/s，松手五帧后速度为 0 并恢复站姿。截图 `replay_run_fire_grip.png` 与 `replay_backpedal.png` 已检查。新版单独霰弹上升 165.07 px，跳跃叠加霰弹为 403.38 px，160 px 缺口仍可跨过。
