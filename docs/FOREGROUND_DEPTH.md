# 下方分段城墙与建筑层级

2026-09-11。用户否决两侧模糊柱旗，改为下方分段城墙。本文件覆盖此前的近景柔焦规范。

## 当前呈现

五段场景各有两组近景石墙，共十组，宽 120–180 逻辑像素。墙体为真实 3D 几何，有立面、压顶、降低的缺口和两处短墙端柱。墙基向下延伸出取景区域，视作近处外墙的局部，不出现悬空底边。墙段位置保持世界坐标；近镜头、上层路线和跳跃时可以自然离开视野，不强行保持屏幕边框。

移除旧版 14 张拉长柱旗及 foreground_soft 模糊材质；不做模糊、屏幕边缘渐隐或透明黑幕。普通不透明石材使用最近邻采样，接受环境光，颜色低于可玩平台。前景不投下会干扰战斗的阴影，也不增加碰撞。

## 素材与编辑

检查现有 atlas_v1.png 后，素石条 Rect2i(668,42,526,62) 足够用于墙面，石砖区域 Rect2i(48,34,548,526) 用于压顶。保留原 imagegen 来源，未生成新图。通过三向投影按世界尺度采样，不把整幅哥特拱门贴满墙面；缺口与厚度由几何表达。

在 Godot 打开 scenes/rooms/near_foreground.tscn 可独立编辑十组墙的位置。每组导出 width 和 end_pier，工具脚本实时重建。节点原点为最高压顶面；两个端柱位置不再额外超过这个上限。场景实例归入主地图 scenery，重置时一起销毁重建，材质接入 F6 白模切换。

景深中心 z=0.95，最靠后实体面 z=0.72，位于可玩平台前面 z=0.675 之外。普通墙顶 y=-3.38，低洼外廊与花园为 -3.90。后两组分别布置于低处实地前沿，并在墙间保留开口，不横跨整段屏幕。

高度按扣除 HUD 后的可见区域计算：640×360 世界画面中，HUD 上界约 y=36、下界 y=290。测试要求墙顶不超过这段可见区域的下方 20%。每隔 32 逻辑像素采样实际平台高度，包括下层路线与机关平台，覆盖 0/80/160 像素空中高度、三把枪的六个远近距离和三档镜头偏移。最高墙顶落在世界画面 y=0.707–0.725，即可见游戏区域下方约 11%–14%；所有采样中的角色脚底与墙顶至少相隔 4 渲染像素。近镜头下不保证低墙始终可见。
