# 六格武器栏与切枪设计

武器栏固定为六格，编号 1–6。当前原型在 1、2、3 格分别放置左轮、霰弹枪和 SMG；4–6 格为空。数字键直接选择对应的非空枪槽，按空槽不会改变当前武器。Q 与鼠标滚轮从当前格向后循环全部非空枪槽，因此当前内容的顺序为 1→2→3→1。

`WeaponController.slots` 始终包含六个位置，空格使用 `null` 表达。每把已获得的枪各有独立 `WeaponRuntime`。离开当前武器会取消未完成的装填，但保留已经装好的弹药与射击冷却；切回空弹或装填被打断的枪时，从头开始当前装填阶段。选择当前枪不取消装填。

`InputFrame.weapon_slot_pressed` 使用从 0 开始的索引，`-1` 表示本帧没有数字选择。键盘动作 `weapon_1` 至 `weapon_6` 对应主键盘 1 至 6。HUD 常驻显示六格；非空、空置与当前格使用不同颜色和括号状态，同时显示当前枪全名、弹量和换弹进度。

验收覆盖：1–3 直选、4–6 空槽不变、Q 走遍全部非空格并跳过空格、切枪不能绕过冷却、各枪弹量独立、装填取消与恢复语义、真实键盘动作进入 `InputFrame`、HUD 六格和当前高亮可见。
