## 本轮完成

三间新房各有不同目标：关钟、查名单、开两侧水闸。E 操作或阅读，J 查看本次运行的调查笔记，M 查看路线。文字阅读暂停世界，滚轮浏览，E、Esc 或对应入口键返回。房间重试恢复本房机关、敌人和补给；已读记录在本次运行中保留，退出后不保存。

地图编辑器增加机关、记录、补给和关联平台，可保存必做目标与房间主题。校验覆盖支撑、头顶净空、唯一机关 ID 和桥梁引用。钟塔机关停止钟声和警示灯；庭院两闸接通连续步道。禁书室另有左轮跳射可达的封存书架。

按用户追加要求，石台全部实体，只有明确镂空的金属格栅可上下穿越。默认平台为实体，渲染与碰撞使用同一属性。盾兵接近目标时不会主动走下悬边，盾击和玩家击退仍可使她坠落。

## 验证方式与边界

实际控制器输入覆盖逐级跳上实体石台、左轮跳射抵达支路、侧边下落、跨房前进、两闸回路、补给与重复使用、阅读暂停与长文滚动、平台底面和 S 下穿差异。真实编辑器验证新机关的添加、存取和撤销；GPU 截图检查五房呈现与阅读界面。

这些检查不等于真人连续试玩。新钟体、书架、水闸和蔷薇仍是采用当前材质与光影的三维灰盒，最终场景美术、跨房返程、磁盘存档和完整章节尚未交付。部分独立测试在退出时提示两个 ObjectDB 对象未释放；未把该提示当成脚本错误，也未声称已经修复。
