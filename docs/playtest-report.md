# 反冲挽歌 原型验证记录

日期：2026-09-08。环境：Windows / Godot 4.7.2 stable official / Compatibility / NVIDIA GeForce RTX 3070。物理步长固定 60 Hz，内部画布 320×180。

最新手感调整：针对空中漂浮与边跑边射滑动，默认改为 Responsive 配置，保留 GDD 参数对照。历史基线数值仍适用于 GDD 配置；最新控制规则、13 项专项检查与前后数据见 [movement-feel.md](movement-feel.md)。

后续更新：已按用户反馈加入 Space 跳跃、imagegen 像素人物、独立持枪与换弹手部、变色圆形装填进度和更完整 HUD。最新结果为 75 项核心检查在三档渲染帧率下通过，10 项玩法回放及 8 项 GPU 截图保存检查通过。普通跳跃 74.49 px，跳跃叠加霰弹 408.24 px。更新说明见 [jump-update.md](jump-update.md)，美术标准见 [ART_STANDARD.md](ART_STANDARD.md)。以下保留初版反冲基线与试玩边界记录；其中 61 项及 7 项为初版计数。

## 键鼠事件回放

`tests/replay_playtest.gd` 在 60 FPS 下使用实际实验室、生产键鼠采集器和自动物理更新。键盘与鼠标按键经 `Input.parse_input_event` 注入；鼠标位置通过 320×180 SubViewport 输入，使用实际相机转换。测试没有直接调用角色 `step()` 或敌人伤害方法。

| 回放顺序 | 观察与结果 |
|---|---|
| A 左移、鼠标右瞄 | 水平速度 −150 px/s，瞄准方向仍向右 |
| 鼠标朝下，霰弹单击 | 消耗一发，上升 166.91 px |
| Q 切枪 | 切到左轮 |
| 下坠中按 R | 装填期间前半秒继续下坠约 250 px，完成后弹量恢复 6 |
| SMG 朝下按住两秒 | 净下降 875 px；配对自由落体 1580 px，占 55.4% |
| D 移动并霰弹向下单击 | 跨过 x=512–672 的 160 px 缺口，落到右侧地面 |
| 固定盾兵正背面分别射击 | 实际弹丸分别造成 3.6 / 43.2 伤害 |

无渲染与 GPU 渲染回放的 7 项玩法检查均通过；GPU 版本另有 3 项截图保存检查通过。结构化结果见 `artifacts/replay_headless.json` 和 `artifacts/replay_results.json`，截图为 `replay_shotgun_hop.png`、`replay_smg_descent.png`、`replay_gap_crossing.png`。已检查回放截图的场景显示，但没有据此声称输入手感已获验收。

每段回放会重置场景、设置记录中的起始位置、清零速度，再稳定三帧；缓降回放开始采样时已有下落速度，因此与上表“静止空中两秒”数值不同。方向伤害使用固定靶，并分别设置玩家正背面位置。这验证了命中收益，没有模拟连续绕背击杀。回放为隔离桌面指针而断开了失焦暂停回调，不能验证原生焦点行为、Tab/Esc/F 键路由和面板点击。

## 尚待完成的原生试玩

当前记录中的数值来自实际 Godot 场景和控制器测试，不是只计算公式。图形检查来自游戏自身渲染。

原生窗口 Computer Use 首次访问授权超时；后续访问窗口成功，但截图接口返回 `SetIsBorderRequired: 不支持此接口 (0x80004002)`，发送 F2 又因 `foreground window did not report a process id` 失败。因此未完成计划要求的一次原生键鼠连续试玩。引擎事件回放不能替代玩家对手感是否自然的评价。

按 README 的顺序仍需实际检查：离地 → 急停 → 跨越 → 缓降 → 换弹落地 → 绕背击杀，并确认窗口缩放后的瞄准、失焦暂停和面板操作。急停的速度变化已由控制器自动检查覆盖；连续操作的容错与节奏仍待体验确认。

## 调参观察

- 左轮的初始跳高只有约 19 px，适合 16 px 教学台阶；不应直接用它验证 32 px 高台。
- 霰弹可以到达预定的一层半高度，优先保留 720 反冲、1500 重力基线。
- SMG 缓降差异明显，且空中装填会丢失托举能力，能表现“弹匣也是机动资源”。
- 盾兵基线正背面差距很大。本轮以验证方向性收益为准，正式关卡前还需玩家试玩确认正面耗时是否过长。
- 本轮未修改文档基线。若连续试玩发现跨越后难以刹停，先调整空中水平控制与超速阻尼；若绕背窗口过短，先降低盾兵转身速度。两项均应通过面板对照测量后决定，不据脚本通过直接定稿。
