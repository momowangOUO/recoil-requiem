# 修道院连通与受击反馈

本次把原来的五个短房间接成一张地图，没有增加新的剧情篇幅。入口仍为 `scenes/game.tscn`，组合地图为 `scenes/rooms/connected_monastery.tscn`。旧分区作为编辑用场景实例保留。

东庭、外廊、警钟塔、禁书室、庭院依次占据 0–960、960–1920、1920–2880、2880–3840、3840–4800 的 X 范围。警钟塔整体上移 48 px，与外廊底层衔接；禁书室入口增加五级石阶，承接塔楼高处出口；庭院入口补上 16 px 门槛。接缝验证包含前进与返回的实体移动、跳跃。

只保留整张地图两端的边界，旧出口不再触发清场和重载。最终出口检查停钟、转运账簿和两侧水闸。死亡回到已记录的检查点，恢复生命和枪械，保留敌人伤亡与机关状态。跨分区不发放生命或弹药。手动重置和应用参数重新建立整张地图。

角色投影仍使用 1920×1088 透明纹理，但窗口随镜头水平移动，中心落在整数逻辑坐标，避免建立超宽纹理。子弹、人物与受击特效共用这一坐标转换。

## 受击

| 对象 | 僵直 | 表现 |
|---|---:|---|
| 主角 | 0.18 秒 | 暖白闪色、血红碎点、沿伤害方向击退；输入不能立即抵消推力 |
| 盾兵正面格挡 | 0.055 秒 | 金色火星与短顿，保持盾牌防御作用 |
| 盾兵侧后、弱点；女枪手 | 0.18 秒 | 闪色、血红碎点与击退；打断正在预警或攻击的动作，进入收招 |

敌人两次僵直触发至少间隔 0.38 秒。期间弹丸继续结算伤害和击退，但不刷新僵直，霰弹和 SMG 不会无限延长同一次僵直。霰弹总冲量仍为 520 / 敌人质量。

僵直冻结角色主动动作，重力与碰撞继续。枪械冷却和已经开始的装填按实际时间推进，受击期间不缓存开火和跳跃。暂停冻结整场游戏。本轮不加入全局停顿；测量模式仍关闭震屏。

受击姿态使用已有作者绘制动作帧的停帧、最多 2 px 局部位移与着色反馈，没有新增专门的受击身体帧。
