# 敌人角色与动画开发标准

2026-09-09，用户确认的强制标准。适用于所有普通敌人、精英与 Boss。

## 角色方向

所有敌人均为美少女角色，以成年女性形象设计。脸、发型和服装剪影必须在 320×180 游戏画面内可辨认。重甲敌人也要保留可见面部，不能以封闭头盔、无脸盔甲或男性骑士替代。护甲重量通过肩甲、盾、姿势和步伐表达。不同敌人的发色、发饰、衣装轮廓和武器应有稳定区分。

画风必须与已接入主角一致：以主角实机 42px 身高、约 12–14px 头部、暗色外轮廓和 2–3 档材质色块为参照。敌人可略高到约 46px，不能采用另一套写实比例、高清渐变或更细的像素密度。每次接入提供主角与敌人同屏对照。裁切须排除低透明杂点及品红键底，不能直接把带杂点的整格缩小。

## 制作与拆件

角色美术由 imagegen 生成，原始提示词与源图随项目保存。禁止以程序几何占位身体代替角色图。优先生成完整身体动作帧以保证自然解剖；需要独立瞄准、拾取或状态控制的武器等才拆件。拆件必须先验收关节、比例与遮挡，不得强行将分别缩放的头、躯干和四肢拼成完整角色。盾兵的固定盾击可以使用手臂与盾一体的完整动作帧。左右肢体复用仅在实际运动与遮挡自然时允许。

每个部件记录源图区域、显示尺寸、关节挂点和层级。手臂必须从肩到肘再到手，盾固定在握持手上；不得出现独立漂浮盾或关节断开。遮挡至少覆盖关节 1–2 个逻辑像素。近远侧肢体排序明确，头发应位于身体后层。碰撞体不随美术摆动或缩放。

共享像素密度、Nearest、无 mipmap。动画最终坐标取整；每个部件的显示尺寸在各状态间固定，不能靠拉伸躯干或整图平移冒充动作。源图品红键底须在运行时可靠去除。所有动作检查左右朝向、原生 1× 和 4×。

## 最低动作交付

| 状态 | 必须可见的变化 | 时间来源 |
|---|---|---|
| 待机 | 呼吸、头发或肩臂轻动，脚底稳定 | 可暂停的视觉时钟 |
| 移动 | 左右腿交替，髋膝踝联动，盾保持持握 | 主动移动速度；纯击退不播放走路 |
| 转向 | 身体与盾朝向一致，不抢先改变伤害朝向 | 实际 facing_angle |
| 蓄力 | 屈膝压低、持盾手后收、身体后倾，明确预警 | WINDUP 0.45 秒 |
| 攻击 | 前腿踏出、手臂伸展、盾前推；视觉与攻击范围一致 | ATTACK 0.15 秒 |
| 收招 | 盾下垂、姿态失衡后回正，后腰弱点清楚开放 | RECOVERY 0.8 秒 |
| 受击 | 短闪白与局部后缩；不重置攻击时钟 | 实际 hit_flash |
| 死亡 | 屈膝倒下、手臂与盾松落，结束于稳定姿态 | DEAD 进入时开始，碰撞立即禁用 |

允许通过完整动作帧、骨骼式拆件或两者结合表现动作，但不接受“单张站姿上下抖动”作为移动动画，也不接受整图旋转作为完整死亡动画。完整帧必须确实包含不同的肢体姿态；拆件方案必须保证盾臂、身体与腿部独立轨道自然，不以拉伸骨段补救坏素材。

## 验收与代码约束

- 美术只读取战斗状态，不修改生命、质量、伤害倍率、攻击时长、碰撞或弱点判定。
- 暂停时动作冻结，重置时视觉时钟与姿态清零；固定靶可以待机，不能自行走路。
- 使用实际 ShieldEnemy 场景渲染待机、两个不同步态、蓄力、攻击、收招、受击、死亡；检查盾牌与手、关节接缝、脚底和弱点位置。
- 运行 tools/run_checks.ps1，检查战斗倍率、击退、状态时长和重置回归。
- 必须把不合格项写入记录；生成图完成不等于动画完成。以游戏内效果验收，不以高清源图代替。
