# 夜景分层与物件贴图

2026-09-10。此次更新覆盖源工程和唯一 Windows 输出。

天空、月亮与远处城堡分别使用独立 PNG 和 Sprite3D，不再使用把三者烘在一起的 skyline_v2。整张连续地图共用一个 NightBackdrop，天空位于 z=-28，月亮 z=-22，城堡 z=-9，近处建筑约 z=-1.5。月亮与天空不会在每段关卡重新出现。

天空横向跟随镜头，保持远处天空覆盖。月亮跟随横向位移的 98%，城堡留在世界坐标；结合透视深度形成远慢近快的运动。城堡向地图两端之外延伸，支持枪械拉远视野。分层参数集中在 scripts/rooms/night_backdrop.gd，可单独修改位置、尺寸及色调。

所有三维实体在贴图模式下都必须有 albedo_texture。石台保留既有石材，铁栏、格栅、黄铜钟、木门、书架、书皮、纸页、钟绳、花叶与血瓶分别使用对应材质。金属、木材采用世界坐标三向投影，纹理不随长物件被拉长；小道具使用单独裁出的材质块，不允许直接采整张图集。材质细节应低对比，避免在缩小时变成满屏噪点。F6 仍是主动关闭贴图的诊断白模模式。

美术源图和运行时拆图保存在 assets/environments/crimson。tools/prepare_environment_layers.py 只做确定性裁切及品红色键透明化，不绘制替代美术。源图若更新，须重新裁切、导入，并在实际 GPU 画面中检查透明边缘、远近遮挡、最大视野和五段场景。

自动检查入口为 tests/test_environment_art.gd，已加入 tools/run_checks.ps1。检查覆盖三次重置后的单一天空/月亮、独立深度、透明底色、所有 MeshInstance3D 的贴图、白模切换恢复和不同层的横向移动。截图验证属于固定输入的引擎渲染检查，不等同于人工键鼠试玩。
